# 对比双栏同步滚动与匹配项聚焦设计

## 目标

提升文档对比页的浏览效率，使用户在双栏之间保持位置感，同时能快速聚焦到对应的差异内容。

## 交互行为

1. 对比结果首次展示时，两栏均停留在文档首页，不自动选中或跳转到第一条差异。
2. 用户手动滚动任一文档栏时，另一栏按可滚动范围的相对进度同步滚动。
3. 用户点击任一栏中的差异块时：
   - 两栏中具有相同 `data-diff-id` 的匹配项同时高亮；
   - 两栏各自将对应匹配项滚动到本栏可视区域的垂直中心；
   - 继续沿用现有 Python 桥接逻辑，在右侧详情面板展示该差异。
4. 用户点击右侧差异卡片时，行为与点击文档栏差异块一致：双栏匹配项高亮并分别居中。
5. 若某项仅存在于一侧，例如新增或删减内容：
   - 存在匹配元素的一栏将该元素居中；
   - 缺少匹配元素的一栏保持同步滚动产生的当前位置，不额外跳转。

## 实现方案

同步滚动采用比例映射：

`进度 = 当前栏 scrollTop / (scrollHeight - clientHeight)`

另一栏的目标位置为：

`目标 scrollTop = 进度 * (另一栏 scrollHeight - clientHeight)`

相比直接复制像素值，该方案能适应两份文档内容长度和段落高度不同的情况。滚动处理器使用重入保护，程序设置另一栏位置时不反向触发新一轮同步，避免抖动和事件循环。

匹配项聚焦沿用模板中的 `focusDiff(diffId)` 边界，并调整文档内差异点击处理器统一调用该函数。每个匹配元素只影响其所在滚动栏，使用居中定位展示语义对应关系。

## 组件边界

- `assets/diff_template.html`
  - 负责双栏滚动事件监听、比例换算、重入保护、差异选择及居中定位。
  - 暴露稳定的全局函数供 Python 调用。
- `app/ui/pages/compare_page.py`
  - 继续负责从右侧卡片触发 `focusDiff(diffId)`。
  - 不承担滚动比例计算，避免 Python 与 WebEngine 之间产生高频通信。
- `tests/ui/test_compare_page.py`
  - 验证模板包含同步滚动和聚焦行为所需的公开函数与事件绑定。
  - 验证 Python 侧卡片点击仍调用匹配项聚焦入口。

## 边界与容错

- 当某栏没有可滚动距离时，其同步目标固定为顶部，且不会出现除零错误。
- 内容重新注入后仍只绑定一组滚动和点击处理器，避免重复监听。
- 初始内容渲染不调用 `focusDiff`，确保页面停留在首页。
- 程序化匹配项居中引发的滚动事件受重入保护，不造成两栏来回校正。
- 平滑居中仅用于用户明确选择差异；普通同步滚动即时跟随，以减少滞后感。

## 验收标准

1. 滚动基准栏时，目标栏按相对进度同步；反向操作同样成立。
2. 两栏内容高度明显不同时，同步滚动仍能同时到达顶部、中部和底部。
3. 快速滚动时没有明显抖动、反复回弹或事件循环。
4. 点击双栏任一差异块或右侧差异卡片时，对应匹配项在两栏中高亮并尽量居中。
5. 单侧新增或删减项不会导致无匹配元素的一栏异常跳转。
6. 首次展示对比结果时保持文档首页。
7. 现有对比页测试全部通过，并新增同步滚动回归测试。
