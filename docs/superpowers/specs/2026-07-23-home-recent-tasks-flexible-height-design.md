# 首页最近对比任务弹性高度设计

## 背景

首页“最近对比任务”表格当前设置了 240px 最大高度，页面布局又在表格下方加入了弹性空白。因此窗口即使仍有可用空间，表格也只能显示少量任务，用户需要频繁使用垂直滚动条。

## 目标

- “最近对比任务”分组和表格自动占用首页剩余垂直空间。
- 较高窗口中直接显示更多任务，减少不必要的表格内滚动。
- 较小窗口中保持现有表格滚动能力，不挤压或隐藏标题、统计卡片和快捷操作。

## 方案

采用 Qt 布局的弹性伸缩能力：

1. 移除任务表格的 240px 最大高度限制。
2. 将“最近对比任务”分组以纵向伸缩因子加入首页主布局，使其取得固定区域之外的剩余空间。
3. 移除分组下方单独占用剩余空间的 stretch。
4. 为任务表格和分组设置可纵向扩展的尺寸策略，明确其布局意图。

首页仍通过现有查询加载最近 10 条任务。表格内容超过当前可见高度时，继续使用 `QTableWidget` 自带的垂直滚动条。

## 未采用的方案

- **提高固定最大高度**：只能改善特定分辨率，在更高或更矮的窗口中仍会浪费空间或产生挤压。
- **根据任务行数计算固定高度**：需要维护表头、行高、边框和主题相关的尺寸计算，复杂度高且仍不能充分利用窗口变化后的剩余空间。

## 修改范围

- `app/ui/pages/home_page.py`
  - 调整“最近对比任务”分组和表格的尺寸策略及主布局伸缩因子。
- `tests/ui/test_home_page.py`
  - 增加布局回归测试，验证表格不再受 240px 最大高度限制，并能够随首页高度增长。

不修改任务查询数量、表格列宽、行内容、操作按钮或其他页面。

## 验收标准

1. 首页窗口增高时，“最近对比任务”框和表格随之增高。
2. 表格不再固定于 240px 最大高度。
3. 窗口高度不足以展示全部任务时，表格仍可垂直滚动。
4. 上方标题、统计卡片和快捷操作保持现有布局。
5. 首页现有 UI 测试及新增布局回归测试通过。
